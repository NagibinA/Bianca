# Bianca Integration for Home Assistant

Интеграция для управления стиральной машиной Candy Bianca через Home Assistant.

![Candy Bianca](/bianca.png)


## 📝 Описание

Интеграция позволяет:
- Управлять стиральной машиной (запуск/остановка стирки)
- Выбирать программу стирки
- Настраивать параметры стирки (температура, отжим, загрязнение и т.д.)
- Отслеживать состояние машины в реальном времени
- Использовать кастомный дашборд с уникальными иконками для управления

## 📋 Требования

- Home Assistant 2024.1 или новее
- Стиральная машина Candy Bianca с поддержкой Wi-Fi
- IP-адрес машины в локальной сети

## 🚀 Установка

### Через HACS (рекомендуется)

1. Добавьте репозиторий в HACS как пользовательский репозиторий
2. Нажмите "Download"
3. Перезапустите Home Assistant

### Вручную

1. Скопируйте папку `custom_components/bianca` в папку `custom_components` вашего Home Assistant
2. Перезапустите Home Assistant

## ⚙️ Настройка

1. Перейдите в **Настройки → Устройства и сервисы → Добавить интеграцию**
2. Найдите "Bianca"
3. Введите IP-адрес стиральной машины
4. Введите название устройства (опционально)
5. Нажмите "Создать"

## 🖥️ Использование

### Основные сущности

| Тип | Сущность | Описание |
|-----|----------|----------|
| binary_sensor | `binary_sensor.bianca_available` | Доступность устройства (ping) |
| sensor | `sensor.bianca_machine_state` | Состояние машины |
| sensor | `sensor.bianca_program` | Текущая программа стирки |
| sensor | `sensor.bianca_remaining_time` | Оставшееся время |
| sensor | `sensor.bianca_temperature` | Температура стирки |
| sensor | `sensor.bianca_spin_speed` | Скорость отжима |
| sensor | `sensor.bianca_error` | Ошибки (если есть) |
| sensor | `sensor.bianca_remote_control` | Статус удалённого управления |

### Селекты для настройки стирки

| Сущность | Описание | Доступные опции |
|----------|----------|-----------------|
| `select.bianca_program` | Программа стирки | Хлопок: Интенсивная, Хлопок, Синтетика, Шерсть, Деликатная, Perfect 20°C, Полоскание, Слив+Отжим, Сохранить свежесть, Perfect rapid 59 мин, Быстрая |
| `select.bianca_temperature` | Температура | зависит от программы |
| `select.bianca_spin` | Скорость отжима | зависит от программы |
| `select.bianca_soil` | Уровень загрязнения | Нет, Мало, Нормально, Очень (зависит от программы) |
| `select.bianca_steam` | Пар | Без пара, С паром (зависит от программы) |
| `select.bianca_pre_wash` | Предварительная стирка | Нет, Есть (зависит от программы) |
| `select.bianca_hygiene` | Гигиеническая стирка | Нет, Есть (при t≥60°C) |
| `select.bianca_anti_crease` | Антисминание | Нет, Есть (зависит от программы) |
| `select.bianca_night_spin` | Ночная стирка | Нет, Есть (зависит от программы) |
| `select.bianca_extra_rinse` | Дополнительные полоскания | Нет, 1, 2, 3 (зависит от программы) |
| `select.bianca_aqua_plus` | Акваплюс | Нет, Есть (зависит от программы) |
| `select.bianca_zoom` | Режим ZOOM | Нет, Есть (зависит от программы) |
| `select.bianca_delay_start` | Отложенный старт | Нет, 30 мин ... 24 часа |

### Сервисы

| Сервис | Описание |
|--------|----------|
| `bianca.start_washing` | Запуск стирки с выбранными параметрами |
| `bianca.stop_washing` | Остановка текущей стирки |

## 🎛️ Дашборд

Интеграция включает кастомный дашборд для управления стиральной машиной.

**Добавление на Lovelace:**

1. Перейдите в режим редактирования Lovelace
2. Нажмите "Добавить карточку"
3. Выберите "Dashboard → Bianca"
4. Сохраните карточку

▶️ **Демонстрация работы:** [Candy](https://drive.google.com/file/d/18bVUknuDNhX_u5HwTAy17B6avzZMyUI8/view)

**Элементы дашборда:**

- Изображение стиральной машины с активными зонами
- Кастомные иконки для выбора программы и настроек
- Индикаторы текущего состояния (цветные/серые)
- Кнопки запуска и остановки

**Логика отображения иконок на дашборде:**

| Режим работы | Что показывают иконки | Кликабельность |
|--------------|----------------------|----------------|
| Стирка (Работает/Пауза) | Текущие значения от API | ❌ Нет |
| Бездействие + remote_control = Выкл | Текущие значения от API | ❌ Нет |
| Бездействие + remote_control = Вкл | Доступные опции для выбранной программы | ✅ Да (если опция доступна) |
| Нет связи (ping = off) | Иконки скрыты | ❌ Нет |

## 📁 Конфигурация программ (файл `programs.json`)

Начиная с версии **2.0.0**, все программы и их опции настраиваются через файл `programs.json`, который находится в папке `custom_components/bianca/`.

### Структура файла `programs.json`

```json
{
  "programs": {
    "ID_программы": {
      "name": "Название программы (отображается в интерфейсе)",
      "pr_code": 65,
      "pr_str": "Текст на дисплее машины (на английском)",
      "options": {
        "temperature": {
          "values": ["0°C", "20°C", "30°C", "40°C", "60°C", "90°C"],
          "default": "60°C"
        },
        "spin": {
          "values": ["0 об/мин", "400 об/мин", "600 об/мин", ...],
          "default": "1000 об/мин"
        },
        "soil": {
          "values": ["Мало", "Нормально", "Очень"],
          "default": "Мало"
        },
        "steam": {
          "values": ["Без пара", "С паром"],
          "default": "Без пара"
        },
        "pre_wash": {
          "values": ["Нет", "Есть"],
          "default": "Нет"
        },
        "hygiene": {
          "values": ["Нет", "Есть"],
          "default": "Нет",
          "depends_on": {
            "option": "temperature",
            "condition": ">=60"
          }
        },
        "anti_crease": {
          "values": ["Нет", "Есть"],
          "default": "Нет"
        },
        "night_spin": {
          "values": ["Нет", "Есть"],
          "default": "Нет"
        },
        "extra_rinse": {
          "values": ["Нет", "1 полоскание", "2 полоскания", "3 полоскания"],
          "default": "Нет"
        },
        "aqua_plus": {
          "values": ["Нет", "Есть"],
          "default": "Нет"
        },
        "zoom": {
          "values": ["Нет", "Есть"],
          "default": "Нет"
        }
      },
      "mutual_exclusion": [
        ["anti_crease", "night_spin"]
      ]
    }
  }
}
```


### Поля файла `programs.json`

| Поле | Описание | Пример |
| :--- | :--- | :--- |
| `ID_программы` | Числовой идентификатор программы (PrNm) | `"1"`, `"2"`, `"3"` |
| `name` | Название программы, отображаемое в интерфейсе | `"Хлопок: Интенсивная стирка"` |
| `pr_code` | Код программы для API (PrCode) | `65`, `2`, `3` |
| `pr_str` | Текст, отображаемый на дисплее машины (английский) | `"Cotton Intensive"` |
| `options` | Объект с настройками всех опций | [см. структуру](#поля-опций-в-options) |
| `mutual_exclusion` | Массив пар опций, которые не могут быть включены одновременно | `[["anti_crease", "night_spin"]]` |

### Поля опций в `options`

| Поле | Описание |
| :--- | :--- |
| `values` | Массив доступных значений для данной опции |
| `default` | Значение по умолчанию |
| `depends_on` | (опционально) Зависимость от другой опции (только для `hygiene`) |

### Доступные опции и их ключи

| Ключ в JSON | Отображаемое имя | Возможные значения |
| :--- | :--- | :--- |
| `temperature` | Температура стирки | `["0°C", "20°C", "30°C", "40°C", "60°C", "90°C"]` |
| `spin` | Скорость отжима | `["0 об/мин", "400 об/мин", ..., "1400 об/мин"]` |
| `soil` | Уровень загрязнения | `["Нет", "Мало", "Нормально", "Очень"]` |
| `steam` | Пар | `["Без пара", "С паром"]` |
| `pre_wash` | Предварительная стирка | `["Нет", "Есть"]` |
| `hygiene` | Гигиеническая стирка | `["Нет", "Есть"]` |
| `anti_crease` | Антисминание | `["Нет", "Есть"]` |
| `night_spin` | Ночная стирка | `["Нет", "Есть"]` |
| `extra_rinse` | Дополнительные полоскания | `["Нет", "1 полоскание", "2 полоскания", "3 полоскания"]` |
| `aqua_plus` | Акваплюс | `["Нет", "Есть"]` |
| `zoom` | Режим ZOOM | `["Нет", "Есть"]` |

## 🛠 Как добавить новую программу

1.  Откройте файл `programs.json`
2.  Добавьте новый блок с уникальным ID (например, `"17"`)
3.  Заполните поля:
    - `name` — название на русском
    - `pr_code` — код программы
    - `pr_str` — текст на дисплее (английский)
    - `options` — настройки опций
    - `mutual_exclusion` — при необходимости
4.  Сохраните файл
5.  **Перезапустите Home Assistant**

## ✏️ Как изменить опции существующей программы

1.  Откройте файл `programs.json`
2.  Найдите нужную программу по ID
3.  Измените нужные поля в `options`:
    - Добавьте или уберите значения в `values`
    - Измените `default`
4.  Сохраните файл
5.  **Перезапустите Home Assistant**

## 🚫 Как добавить взаимоисключение

```json
"mutual_exclusion": [
  ["anti_crease", "night_spin"]
]
```


Это означает, что опции `anti_crease` и `night_spin` не могут быть "Есть" одновременно.

### Как добавить зависимость (только для гигиены)

```json
"hygiene": {
  "values": ["Нет", "Есть"],
  "default": "Нет",
  "depends_on": {
    "option": "temperature",
    "condition": ">=60"
  }
}
```

Это означает, что опция `hygiene` доступна только когда температура ≥ 60°C.

## 🐛 Устранение неполадок

### Интеграция не создаёт сущности

1. Проверьте, что файлы находятся в правильной папке
2. Перезапустите Home Assistant
3. Проверьте лог на наличие ошибок

### Не отображаются иконки в дашборде

1. Проверьте, что устройство доступно (`binary_sensor.bianca_available = on`)
2. Проверьте, что удалённое управление включено (`sensor.bianca_remote_control = Вкл`)
3. Очистите кэш браузера (Ctrl+F5)
4. Проверьте, что файлы иконок скопированы в `/local/community/bianca/`

### Не меняются опции при смене программы

1. Проверьте версию интеграции (должна быть 2.0.0+)
2. Проверьте, что файл `programs.json` существует и не содержит ошибок
3. Перезапустите Home Assistant
4. Проверьте лог на наличие ошибок

### Не работает селект отложенного старта

1. Проверьте, что `select.bianca_delay_start` существует
2. Убедитесь, что версия интеграции 2.0.1+

### Не работают кастомные иконки

Кастомные иконки автоматически регистрируются при загрузке интеграции. Если иконки не отображаются:

1. Проверьте, что файл `bianca-icons.js` существует в папке `custom_components/bianca/`
2. Проверьте, что файл скопирован в `/local/community/bianca/bianca-icons.js`
3. Проверьте, что в `configuration.yaml` нет конфликтующих настроек
4. Перезапустите Home Assistant

### Ошибка в файле `programs.json`

Если в файле `programs.json` есть синтаксическая ошибка, интеграция не загрузится. Проверьте JSON на валидность через любой онлайн-валидатор.
