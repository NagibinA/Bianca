# Bianca Integration for Home Assistant

Интеграция для мониторинга стиральных машин Bianca (Candy) через Home Assistant.

## Возможности

- Мониторинг состояния стиральной машины в реальном времени
- Отображение текущей программы стирки
- Контроль температуры и скорости отжима
- Отслеживание оставшегося времени и отложенного старта
- Мониторинг ошибок с текстовой расшифровкой
- Отображение всех дополнительных опций (предварительная стирка, акваплюс, режим ZOOM и т.д.)

## Установка

### Через HACS (рекомендуется)

1. Добавьте репозиторий `https://github.com/NagibinA/bianca` в HACS как пользовательский репозиторий
2. Установите интеграцию "Bianca"
3. Перезагрузите Home Assistant

### Вручную

1. Скопируйте папку `custom_components/bianca` в вашу директорию `custom_components`
2. Перезагрузите Home Assistant

## Настройка

1. Перейдите в **Настройки → Устройства и службы → Добавить интеграцию**
2. Найдите "Bianca" и нажмите на него
3. Введите IP-адрес вашей стиральной машины (например, `192.168.1.31`)
4. Нажмите "Подтвердить"

## Поддерживаемые устройства

Стиральные машины Bianca (Candy) с поддержкой WiFi и API-эндпоинтом `/http-read.json?encrypted=0`

## Сенсоры

### Основные сенсоры

| Сенсор | Описание |
|--------|----------|
| WiFi статус | Разрешено или запрещено удалённое управление |
| Ошибка | Код и описание ошибки |
| Состояние машины | Бездействие, работает, пауза, завершено и т.д. |
| Программа стирки | Текущая выбранная программа |
| Фаза программы | Предварительная стирка, стирка, полоскание, отжим и т.д. |
| Уровень загрязнения | Низкий, средний, высокий |
| Температура стирки | В градусах Цельсия |
| Скорость отжима | В RPM |
| Оставшееся время | В секундах |
| Отложенный старт | В секундах |
| Язык дисплея | Язык интерфейса устройства |

### Бинарные сенсоры (Вкл/Выкл)

- Пар
- Предварительная стирка
- Гигиеническая стирка
- Анти сминание
- Ночной отжим
- Полоскание 1, 2, 3
- Акваплюс
- Режим ZOOM

## Интервал обновления

Данные обновляются каждые 20-30 секунд (по умолчанию 25 секунд).

## Известные ограничения

- Только режим чтения (без отправки команд на устройство)
- Требуется статический IP-адрес для устройства

## Расшифровка кодов ошибок

| Код | Описание |
|-----|----------|
| 0 | Нет ошибок |
| 2 | Машина не может набрать воду |
| 3 | Стиральная машина не сливает воду |
| 4 | Слишком много пены и/или воды |
| 7 | Проблема с дверцей |
