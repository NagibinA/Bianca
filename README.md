# Bianca Integration for Home Assistant

Интеграция для управления стиральной машиной Candy Bianca через Home Assistant.

|Dashboard  Bianca | Dashboard  Bianca Simple |
|--------|----------|
| ![Candy Bianca](/bianca.png) | ![Candy Bianca](/bianca-simple.png) |

## 📝 Описание

Интеграция позволяет:
- Управлять стиральной машиной (запуск/остановка стирки)
- Выбирать программу стирки
- Настраивать параметры стирки (температура, отжим, загрязнение и т.д.)
- Отслеживать состояние машины в реальном времени
- Использовать кастомный дашборд с уникальными иконками для управления
- При необходимости скачивает и устанавливает card-mod.js с автоматической регистрацией

## 📋 Требования

- Home Assistant 2024.1 или новее
- Стиральная машина Candy Bianca с поддержкой Wi-Fi
- IP-адрес машины в локальной сети

## 🚀 Установка

### Через HACS (рекомендуется)

1. Добавьте репозиторий в HACS как пользовательский репозиторий
2. Нажмите "Download"
3. Перезапустите Home Assistant

### Вручную

1. Скопируйте папку `custom_components/bianca` в папку `custom_components` вашего Home Assistant
2. Перезапустите Home Assistant

## ⚙️ Настройка

1. Перейдите в **Настройки → Устройства и сервисы → Добавить интеграцию**
2. Найдите "Bianca"
3. Введите IP-адрес стиральной машины
4. Введите название устройства (опционально)
5. Нажмите "Создать"

### Основные сущности

| sensor | `sensor.bianca_program` | Текущая программа стирки |
| sensor | `sensor.bianca_remaining_time` | Оставшееся время |
| sensor | `sensor.bianca_temperature` | Температура стирки |
| sensor | `sensor.bianca_spin_speed` | Скорость отжима |
| sensor | `sensor.bianca_error` | Ошибки (если есть) |
| sensor | `sensor.bianca_remote_control` | Статус удалённого управления |

| Сущность | Описание | Доступные опции |
|----------|----------|-----------------|
| `select.bianca_program` | Программа стирки | Хлопок: Интенсивная, Хлопок, Синтетика, Шерсть, Деликатная, Perfect 20°C, Полоскание, Слив+Отжим, Сохранить свежесть, Perfect rapid 59 мин, Быстрая |
| `select.bianca_temperature` | Температура | зависит от программы |
| `select.bianca_spin` | Скорость отжима | зависит от программы |
| `select.bianca_soil` | Уровень загрязнения | Нет, Мало, Нормально, Очень (зависит от программы) |
| `select.bianca_steam` | Пар | Без пара, С паром (зависит от программы) |
| `select.bianca_pre_wash` | Предварительная стирка | Нет, Есть (зависит от программы) |
| `select.bianca_hygiene` | Гигиеническая стирка | Нет, Есть (при t≥60°C) |
| `select.bianca_anti_crease` | Антисминание | Нет, Есть (зависит от программы) |
| `select.bianca_night_spin` | Ночная стирка | Нет, Есть (зависит от программы) |
| `select.bianca_extra_rinse` | Дополнительные полоскания | Нет, 1, 2, 3 (зависит от программы) |
| `select.bianca_aqua_plus` | Акваплюс | Нет, Есть (зависит от программы) |

## 🎛️ Дашборд

Интеграция включает кастомные дашборды для управления стиральной машиной.

**Добавление на Lovelace:**

1. Перейдите в режим редактирования Lovelace
2. Нажмите "Добавить карточку"
3. Выберите "Dashboard → Bianca" или/и "Dashboard → Bianca Simple"
4. Сохраните карточку



**Элементы дашборда:**

- Изображение стиральной машины с активными зонами
- Кастомные иконки для выбора программы и настроек
- Индикаторы текущего состояния (цветные/серые)
- Кнопки запуска и остановки

## 📁 Конфигурация программ

Интеграция включает Web страницу для управления программами стирки.

---
![Candy Bianca](/bianca-edit.png)
### 🛠 Как добавить новую программу или отредактировать существующую
1. Нажмите иконку 🗄️➕ на дашборде
2. Откроется WEB страница "Bianca - Управление программами"
3.  Заполните поля:
    - `Название программы` — название на русском
    - `Pr` — код программы    
    - `PrCode` — код подпрограммы
    - `PrStr` — текст на дисплее (английский)
    - `options` — настройки опций
    - `mutual_exclusion` — при необходимости
4.  Нажмите Сохранить
5.  **Перезапустите Home Assistant**
