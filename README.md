# Bianca Integration for Home Assistant

Интеграция для мониторинга стиральных машин Bianca (Candy).

## Установка через HACS

1. Добавьте репозиторий `NagibinA/bianca` как пользовательский
2. Установите интеграцию "Bianca"
3. Перезагрузите Home Assistant

## Настройка

1. **Настройки → Устройства и службы → Добавить интеграцию → Bianca**
2. Введите IP-адрес стиральной машины
3. Введите название устройства (по желанию)
4. Нажмите "Подтвердить"

- Скорость отжима

- Отложенный старт
- Язык дисплея
- Пар

- Гигиеническая стирка
- Анти сминание
- Ночной отжим
- Полоскание 1, 2, 3
